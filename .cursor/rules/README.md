# Cursor Rules — yunusardaguney.com

[humanstack/vibe-coding-template](https://github.com/humanstack/vibe-coding-template) AI workflow'undan uyarlanmış, **frontend-only portföy** kuralları.

## Kurallar

| Dosya | Ne zaman |
|-------|----------|
| `project-overview.mdc` | Her zaman (always apply) |
| `frontend/nextjs-standards.mdc` | `src/**/*.tsx`, `src/**/*.ts` |
| `frontend/portfolio-content.mdc` | config, data, types |
| `development-workflow.mdc` | package.json, next.config, README |
| `templates/react-component-template.mdc` | Manuel: `@react-component-template` |

## Şablonda olmayan (bilerek)

Backend, Supabase, veritabanı migration ve API şablonları — v1 portföy kapsamında yok.

## Hızlı başlangıç

1. Cursor'da bu repo açıkken kurallar otomatik uygulanır.
2. Büyük işlerde `product.md` + `CONTEXT.md` dosyalarını @ ile ekle.
3. Yeni bölüm bileşeni için `@react-component-template` kullan.

Alternatif: kök `AGENTS.md` (tek dosya özet).
